# リール一括文字起こしアプリ

Instagram のアカウントを指定すると、そのアカウントのリール動画をまとめてダウンロードして文字起こしします。
ご自身の PC で動くアプリです（ブラウザで操作します）。

> 自分のアカウントや、許可を得たアカウントの動画に使ってください。
> ログインには、普段使いとは別の「捨てアカウント」をおすすめします。

## 準備（最初の1回だけ）

1. **Python をインストール**します：https://www.python.org/downloads/
   - Windows の場合は、インストール画面の **「Add Python to PATH」にチェック**を入れてください。
2. この `reel-transcriber` フォルダを、PC の好きな場所（デスクトップなど）に置きます。

## 使い方

1. フォルダの中のファイルを**ダブルクリック**します。
   - Mac：`start_mac.command`
     - 「開発元を確認できない」と出たら、**右クリック →「開く」**を選んでください。
   - Windows：`start_windows.bat`
     - 「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」**を押してください。
2. 黒い画面（ターミナル）が開き、しばらくするとブラウザでアプリが開きます。
   初回は準備に数分かかります。
3. ブラウザの画面で：
   - **① ログイン**：Instagram のユーザー名とパスワードを入れて「ログイン」
     （2回目以降はパスワード不要です）
   - **② 対象アカウント名**を入れて「開始」
4. 終わると、画面に一覧が出ます。「CSVで保存」「テキストで保存」ボタンでダウンロードできます。

使い終わったら、黒い画面（ターミナル）を閉じれば終了です。

## 保存場所

`output/対象アカウント名/` フォルダに保存されます。

- `xxxx.mp4` … 動画
- `xxxx.txt` … 動画ごとの文字起こし
- `_一覧.csv` … 投稿日・URL・キャプション・文字起こしの一覧（Excel で開けます）
- `_全文.txt` … 全部の文字起こしをまとめたもの

途中で止まっても、もう一度「開始」すれば済んだ分は飛ばして続きから進みます。

## うまくいかないとき

- **ログインできない**：一度 Instagram のアプリかブラウザでそのアカウントにログインし、確認画面が出ていれば済ませてから再度お試しください。
- **「一時的に制限されました」と出る**：取得しすぎです。数時間あけてから再開してください。最大件数を少なめ（20〜50件）にするのがおすすめです。
- **文字起こしが遅い**：「文字起こしの精度」を「速い（small）」にしてください。
