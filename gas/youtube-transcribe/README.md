# YouTube → スプレッドシート → Gladia 文字起こし

YouTubeチャンネル `@tonyobyo_amakana` の全動画を、スプレッドシートに書き出します。

- A列：タイトル
- B列：URL
- F列：文字起こし(Gladia)
- G〜I列：管理用(ジョブID・ステータス・送信日時)。二重送信を防ぐために使うので、消したり書き換えたりしないでください。

## セットアップ

1. スプレッドシートを開き、**拡張機能 → Apps Script** を開きます。
2. `Code.gs` の中身を貼り付けます。
3. 左の「サービス +」から **YouTube Data API v3** を追加します(または `appsscript.json` の内容をそのまま使います)。
4. **プロジェクトの設定 → スクリプト プロパティ** に `GLADIA_API_KEY` を追加し、値にキーを入れます。キーはコードに直接書かないでください。
5. 以前のコード(`transcribeAll`)のトリガーが残っている場合は、**必ず削除**してください。別のプロジェクトにある場合は、そのプロジェクトの「トリガー」画面から削除します。

## 実行の順番

1. `importVideos` を実行します。動画がA・B列に追加され、ログに合計時間(費用の目安)が出ます。何回実行しても重複しません。
2. `processTranscriptions` を**手動で1回**実行します。1本だけGladiaに送られます。数分後にもう一度実行して、F列に文字起こしが入ることを確認してください。
3. 問題なければ `setupTrigger` を実行します。5分ごとに自動で処理し、全部終わるとトリガーは自動で消えます。
4. 途中で止めたいときは `stopTrigger` を実行します。

## 費用を抑えるしくみ

- 各行がGladiaに送られるのは**一度だけ**です。送る前にH列へ「送信中」と記録します。
- ジョブIDを保存しておき、結果は次回以降の実行で取りに行きます。待ち時間が切れても、支払い済みの結果が失われません。
- エラーになった行は自動で再送しません。再送したい行だけ、G・H列を空にしてください。
- 同時実行はロックで禁止しています。
- 1日の送信は `DAILY_SUBMIT_LIMIT` 本(初期値10本)までです。
- 文字起こしはセルの文字数上限(5万文字)に収まるよう切り詰めます。書き込みエラーで送り直しになることはありません。
