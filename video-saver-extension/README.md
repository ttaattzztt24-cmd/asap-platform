# LP Video Saver（Chrome 拡張機能）

開いているページ（UTAGE の LP など）で再生された動画を検出して、MP4 で保存する Chrome 拡張機能です。

> **ご利用にあたって**
> 保存してよいのは、ご自身の動画か、権利者（クライアントなど）から保存の許可をもらった動画だけです。
> クライアントの動画を扱うときは、「LP 動画のバックアップを依頼します」といった内容をメールなどで残しておいてください。
> 暗号化（DRM / AES-128）された動画には対応していません。保護を回避する機能もありません。

## インストール方法

1. このフォルダ（`video-saver-extension`）をパソコンに置く
2. Chrome で `chrome://extensions` を開く
3. 右上の「**デベロッパー モード**」をオンにする
4. 「**パッケージ化されていない拡張機能を読み込む**」を押し、このフォルダを選ぶ
5. ツールバーのパズルアイコンから「LP Video Saver」をピン留めする

## 使い方

1. 動画のある LP を開く（会員サイトの場合は、閲覧用のアカウントでログインしておく）
2. **動画を再生する**（再生が始まると拡張機能のアイコンに件数が出ます）
3. アイコンを押すと、検出した動画の一覧が出る
4. 「ダウンロード」を押す
   - **動画**（MP4 など）: そのまま Chrome のダウンロードで保存されます
   - **HLS**: 保存用のタブが開きます。画質を選んで「ダウンロード開始」を押すと、MP4 にまとめて保存します

HLS は 1 つの動画に対して複数の URL（全体用のものと画質ごとのもの）が出ることがあります。どれを選んでも保存できますが、画質を選べる全体用（`master.m3u8` や `playlist.m3u8` など）を選ぶのがおすすめです。

## 対応状況

| 形式 | 対応 |
|---|---|
| MP4 / WebM などの動画ファイル | ◯ |
| HLS（MPEG-TS） | ◯（MP4 に変換。オフにすると .ts で保存） |
| HLS（fMP4） | ◯ |
| 暗号化された HLS / DRM | ✕ |
| YouTube / Vimeo の埋め込み | ✕（それぞれのサービスの規約に従ってください） |

## うまくいかないとき

- **一覧に何も出ない** → ページを再読み込みして、動画を数秒再生してからアイコンを押してください
- **「取得に失敗しました（HTTP 403）」** → 動画の URL に有効期限がある可能性があります。LP を開き直して、もう一度再生してから試してください
- **保存した動画が長いと時間がかかる** → 保存が終わるまで、保存用のタブは閉じないでください

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定 |
| `background.js` | 通信を監視して、タブごとに動画の URL を記録する |
| `popup.html` / `popup.js` | 検出した動画の一覧を表示する |
| `download.html` / `download.js` | HLS のセグメントを取得して、1 つのファイルにまとめる |
| `hls.js` | m3u8 プレイリストのパーサー |
| `vendor/mux-mp4.min.js` | MPEG-TS → MP4 の変換（[mux.js](https://github.com/videojs/mux.js) 7.1.0, Apache-2.0） |
